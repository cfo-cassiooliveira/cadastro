Como preparar o arquivo

  • A primeira linha é o cabeçalho, exatamente assim:

  • Nome, e-mail e CPF são obrigatórios; o telefone é opcional.
  • O CPF pode ter pontos e hífen. Pessoas repetidas no arquivo são ignoradas.
  • Salve como CSV com codificação UTF-8.
